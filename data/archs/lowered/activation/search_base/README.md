# fig15 pinned search base

Frozen characterization inputs for `experiments/fig15_reduction`: the
activation eval archs in the parent directory have no in-repo generator, so
they ship as-is, and the mapping-pool search arch is pinned here at the same
characterization vintage to keep the fig15 search and eval bases consistent.
The identically-named arch under `data/archs/lowered/geometry_sweep/hbm_pim/`
is a derived output generated by `data/ppa/generate_ppa.sh` (used by
fig12) and is intentionally not used by fig15.
